# Employee Attrition Analysis
**Business Analyst Portfolio Project** - Predicting employee turnover using IBM HR Dataset

## Project Overview
- **Dataset**: 1,470 employee records with 35 features
- **Goal**: Identify attrition drivers and build predictive model
- **Skills**: EDA, Statistical Analysis, Visualization, ML Classification

## Key Findings
- **16.1%** overall attrition rate
- **Young employees (<35)** have 2x higher attrition
- **Overtime workers** 3x more likely to leave
- **Model Accuracy**: 88% (Random Forest)
